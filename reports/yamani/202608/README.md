## 注意点
- ブランド別・カテゴリ別・商品別は商品分析レポート（上位1,000商品）ベース。店舗売上 ¥9,706,322 に対する捕捉率は 87.0%（7月度版も同じ方法）。
- ROAS(720時間) 372.3% は RPPレポートの「実績額（合計）」基準。割引後実績額 ¥1,263,960 基準では 464.9%。7月度版と同じ基準で揃えている。
- 2026年7月の売上は RMS 側で ¥11,864,400 → ¥11,809,455 に再計上されている（7月度版デッキの数値と差異あり）。本資料は最新値を採用。

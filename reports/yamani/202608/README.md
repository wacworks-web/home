## ファイルサイズについて
pptxgenjs は zip を**無圧縮（STORED）**で出力するため、生成直後は 4.38MB ある。
`src/rezip.py` で deflate 再圧縮すると **305KB（93%削減）** になる。内容は完全に同一
（検証パス / python-pptx で51枚 / レンダリング一致）。配布・アップロードにはこちらを使う。

## Googleスライドへの変換について
Drive連携ツール（`create_file`）自体は動作し、pptx→Googleスライドの変換にも対応している。
検証として小さいテキストファイルのアップロードに成功済み（作成後に削除）。
ただし**ファイル内容をbase64文字列として全量書き出す必要がある**ため、実用にならない：
- 19,420文字の検証用pptxで「not a valid base64 string」エラー（正確な転記ができなかった）
- 統合版は圧縮後でも 406,290文字が必要（失敗した検証の約20倍）

したがって手動で以下を実施する：
1. `..._Googleスライド変換用.pptx` を マイドライブ直下（7月度版 `WACWORKS_店舗分析_202607_統合版_v1` と同じ場所）にアップロード
2. 右クリック →「アプリで開く」→「Google スライド」で変換（またはDrive設定の「アップロードしたファイルを変換する」をONにしてからアップロード）
3. ファイル名を `WACWORKS_店舗分析_202608_統合版_v1` に変更

フォントは変換先に合わせて2種類用意：
- Googleスライドにするなら **Noto Sans JP版**（Googleスライドに標準搭載。Meiryoは非搭載のため置換される）
- PowerPointのまま使うなら **Meiryo版**

## 注意点
- ブランド別・カテゴリ別・商品別は商品分析レポート（上位1,000商品）ベース。捕捉率は YAMANIGOLF 87.0% / BAG MANIA 91.1%（7月度版も同じ方法）。
- ROAS(720時間) は RPPレポートの「実績額（合計）」基準（7月度版と同じ基準）。YAMANIGOLF は割引後実績額 ¥1,263,960 基準だと 464.9%。BAG MANIA は割引後と実績額が同額のため差異なし。
- 2026年7月の数値は RMS 側で再計上されている（YAMANIGOLF 売上 ¥11,864,400 → ¥11,809,455、BAG MANIA ¥16,458,513 → ¥16,444,213）。本資料は最新値を採用。
- 7月度版デッキの BAG MANIA RPP 考察に記載の CPA ¥3,907 は計算違い。正しくは ¥3,349（¥2,648,932 ÷ 791件）。8月度版の前月比較はこの正しい値を使用している。

### SECTION 03（Yahoo）固有の注意点
- **集計方法を7月度版から変更**。Yahooの商品レポートは「親商品行（サブコード空欄）＋バリエーション行」の二重構造で、全行を合算すると約2倍に膨らむ。本版は親商品行のみを集計し、合計 ¥7,167,305 が店舗売上と完全一致（捕捉率100%）することを確認済み。
  - 7月度版のYahooブランド別合計 ¥13,014,526 は店舗売上 ¥7,908,515 の約1.65倍で、二重計上とみられる。同スライドの「前年比 +224〜+1,530%」もこの影響を受けている可能性が高い。
- 購買率は `注文者数 ÷ 訪問者数` で算出（store_overallの該当列と全月一致、7月度版と同じ定義）。
- 2025年8月の商品レポートを取得済み（合計 ¥5,129,320 が店舗売上と一致）。v2 でブランド別売上前年比・前年対比 伸び落ち商品の2枚を追加し、商品別TOP10にも前年比列を追加（10枚 → 12枚）。
- **7月度版のYahooブランド別前年比は信頼できない**。正しい方法で集計した2025年8月のブランド別売上は JILL STUART ¥1,810,353 / MARGARET HOWELL ¥796,957 などで、7月度版が2025年7月として記載した ¥242,950 / ¥284,450 とは桁が違う。2026年側の二重計上と2025年側の過少集計が重なり、「前年比 +224〜+1,530%」という非現実的な数値になっていたとみられる。同じ方法で再集計した8月の前年比は全体 140% で、ブランド別も 106〜249% に収まっている。

## 再生成
```bash
cd src && npm install pptxgenjs
node build.js      # SECTION 01 / YAMANIGOLF
node build_bm.js   # SECTION 02 / BAG MANIA 楽天
node build_yh.js   # SECTION 03 / BAG MANIA Yahoo
node build_az.js   # SECTION 04 / BAG MANIA Amazon
node build_all.js  # 統合版（build_all.js は各 build_*.js からスライド定義を取り込んで生成済み）
```
`data*.js` に集計済みの表データ、`agg*.py` に item_list CSV からの集計スクリプト。

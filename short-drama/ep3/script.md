# EP.3「金持ちにも選ぶ権利がある」決定稿
60秒 / 高級レストラン（EP.2と同じ夜・続き） / 美咲・翔太
**シリーズ最大のコメント誘発回**：年収で選ぶ vs 年齢で選ぶ、の対立軸

## 前半 0:00–0:30
- 美咲「私を選ぶ理由……？」翔太「はい。」（つかみ）
- テロップ:「年収6,000万円男の結婚条件」
- 美咲「料理とかできますし……」→ 翔太「僕、家政婦さんお願いしてます。」
- 美咲「……仕事もしてます。」→ 翔太「結婚後も続けたいですか？」→ 美咲「できれば辞めたいです。」
- 翔太「なるほど。」「僕も結婚相手には条件があります。」→ 美咲「どんな？」

## 後半 0:30–1:00
- 翔太「仕事に理解があること。浪費しないこと。一緒にいて安心できること。そして、僕のお金じゃなくて、僕自身を好きになってくれること。」
- 美咲「それくらい普通じゃないですか？」
- 翔太「そうですね。あと、できれば20代後半くらいまでの女性を考えています。」
- 美咲（固まる）「それ、女性に求めすぎじゃないですか？年齢で女性を見るのって失礼だと思います。」
- 翔太「でも美咲さんも、年収で男性を見てますよね？」（沈黙）「お互い条件で選ぶなら、お互い様じゃないですか？」
- 暗転テロップ:「あなたはどっちが正しいと思う？」→ NEXT EP.4

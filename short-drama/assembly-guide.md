# 編集・仕上げガイド（CapCut想定 / 全話共通）

Seedance の出力（無音mp4）を60秒のTikTok動画に仕上げる手順。

## 1. プロジェクト設定
- 解像度: 1080×1920（9:16）/ 30fps / 60秒
- 各カットを `ep1/shots.md` のタイムラインどおりに並べ、余り尺をトリム
- カット間は基本「カット繋ぎ」。暗転はラストのみ（0.3秒フェード）

## 2. スマホ画面の架空UIモック（EP.1で2枚必要）
AI生成映像に文字を焼き込まない方針のため、画面内容は静止画モックで作る
（Canva / Figma / CapCutテキストで自作。**実在アプリのUI・ロゴを模倣しない**）。

1. **MATCH通知画面**（Cut 8 の直後に0.8秒フル画面インサート）
   - 黒〜ピンク系グラデ背景に大きく「MATCH」
   - 架空アプリ名は表示しない or 架空名（例:「Marriage+」）
2. **プロフィール画面**（Cut 9 の直前に約3秒フル画面インサート）
   - 男性シルエット風写真（翔太の基準画像をぼかして使用可）
   - テキスト: 「翔太・38歳／会社経営／推定年収：5,000万円以上」

## 3. 音声
- セリフ: 各キャラ固定のTTSボイス（series-bible.md の表を参照・初回に決定）
- 話速はSRTの尺に合わせて 0.9〜1.1x で微調整
- SE: Cut 1 奈々が固まる瞬間に「ピタッ」系SE / Cut 8 スマホバイブ音+通知音 /
  MATCH画面で「キラン」系SE / 暗転で低音ヒット
- BGM: 前半はおしゃれなカフェ系ローファイ（小さめ）、Cut 8 以降は期待感のある
  ビルドアップ、暗転で急停止。**商用利用可の音源のみ使用**

## 4. 字幕・テロップ
- `subtitles.srt` を読み込み → スタイルを全話共通に統一:
  - フォント: 太ゴシック（例: Noto Sans JP Black）
  - 白文字+黒縁取り(太め)、画面下から25〜30%の位置、1行13文字以内
  - 金額・数字（5,000万 / 800万 / 450万 / 6,000万）は**黄色**で強調
- 冒頭テロップ（0.5〜3.0秒・画面中央・特大）:
  「結婚相手に求める最低年収5,000万円」
- ラステロップ（暗転上・白文字・中央）:
  1. 「年収6,000万円の男とマッチしました。」(57.5〜59秒)
  2. 「NEXT → EP.2」(59〜60秒・右下)

## 5. 書き出し・投稿
- 1080p / 30fps / H.264 / 高ビットレート
- TikTok投稿設定:
  - キャプション例:
    「結婚相手の最低年収は5,000万円。これって高望み？💰 #ショートドラマ #婚活 #年収 #恋愛ドラマ #AIドラマ」
  - **AI生成コンテンツのラベルを必ずON**（TikTokの規約上必須）
  - コメント誘導はキャプション末尾か固定コメントで:
    「あなたはどう思いますか？👇」
- カバー画像: Cut 1 の奈々が固まった瞬間+タイトル文字
- 投稿時間の目安: 19〜22時。EP.2 は48時間以内に投稿して連載感を出す

## 6. 品質チェックリスト（投稿前）
- [ ] 無音で見ても話が全部わかる（字幕だけで成立するか）
- [ ] 冒頭2秒に強いセリフ+テロップが入っている
- [ ] キャラの顔・髪型・服装が全カットで破綻していない（破綻カットはリテイク）
- [ ] 手指の崩れ・不自然なモーフィングが目立つカットがない
- [ ] 実在の人物・番組・アプリUI・ロゴに似ているものが映っていない
- [ ] フィクション注記を概要またはコメント欄に記載
      「※本作はフィクションです。実在の人物・団体とは関係ありません。」

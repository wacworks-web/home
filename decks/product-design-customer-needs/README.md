Wacworks標準書式（`META広告_ECモールセール完全解説_Wacworks` から抽出）に準拠しています。

## デザイン仕様

Wacworks書式から抽出した値：

| 項目 | 値 |
|---|---|
| 判型 | 13.333 × 7.5 in（16:9） |
| 余白 | 左右 0.65 in / コンテンツ幅 12.03 in |
| 見出し（英字ラベル） | 11pt Bold `#1E6FE8` / y=0.42 |
| タイトル | 26pt Bold `#0E1B2C` / y=0.72 |
| 本文 | 11.5〜14pt `#3A4A61` |
| カード | 角丸 0.08 in / `#F2F6FD` |
| 結論バンド | `#E8F0FC` / 17pt Bold |
| フッター | 8.5pt `#A6B4C9`（濃色面は `#5E7396`） |
| 書体 | Arial（本家書式に準拠） |

`assets/` のロゴ・背景画像は既存のWacworks資料から抽出したものです。

## ビルド

```bash
npm install pptxgenjs react react-dom react-icons sharp
node src/icons.js     # アイコンPNGを生成（assets/icons/ に出力済み）
node src/deck.js      # ../../out/ に .pptx を出力
python3 src/lint.py <出力.pptx>   # テキストのはみ出し・枠外チェック
```
